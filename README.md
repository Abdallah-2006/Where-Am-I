# دليل مواصلات مصر | Egypt Transit Guide 🇪🇬

تطبيق تفاعلي مفتوح المصدر يُساعد المواطنين والزوار على تخطيط رحلاتهم ومعرفة مسارات وسائل النقل العام والخاصة في مختلف مدن ومحافظات جمهورية مصر العربية.

---

## 🌟 مميزات التطبيق

* **تغطية شاملة وقابلة للتوسع:** دعم التوسع الجغرافي ليشمل كافة المحافظات بمرونة كاملة.
* **تخطيط الرحلات والمسارات:** البحث عن أفضل المسارات والتنقّلات بين المحطات بكل سهولة.
* **خرائط تفاعلية:** عرض المحطات وخطوط سير وسائل النقل باستخدام خرائط تفاعلية دقيقة.
* **دليل التعريفات والمواقف:** توضيح أسعار الرحلات الرسمية وأماكن الموقف الخاصة بكل مدينة.
* **واجهة وقابليّة تخصيص واسعة:** تصميم سلس ومتجاوب مع جميع الشاشات مع نظام ألوان (Theme) موحد ومستقل.

---

## 🎨 تخصيص الواجهة والثيم (Theming)

جميع ألوان الواجهة، ألوان وسائل النقل، الظلال، وحالات العناصر مجمّعة ومُعرفة داخل `:root` في ملف:
`src/index.css`

يمكنك تغيير الهوية البصرية للتطبيق بالكامل من مكان واحد عبر تعديل متغيرات الـ CSS هناك.

---

## 🏙️ كيفية إضافة مدينة أو محافظة جديدة

تم بناء المعمارية البرمجية لتسهيل مساهمة المطورين في إضافة مدن جديدة:

1. **إنشاء ملف المدينة:** قم بنسخ `src/data/cities/example-city.ts` إلى ملف جديد باسم المدينة (مثال: `cairo.ts`).
2. **ضبط البيانات الأساسية:** عدّل الـ `id`، الاسم بالعربية والإنجليزية، المحافظة، وإحداثيات مركز الخريطة.
3. **إضافة المحطات والخطوط:** جهّز بيانات المحطات وخطوط السير والتعريفات الخاصة بالمدينة الجديدة.
4. **تسجيل المدينة:** أضف استيراد الملف الجديد في `src/data/cities/index.ts` وأدرجها ضمن مصفوفة `CITIES`.

> **ملاحظة:** تتوفر بيانات مدينتي القاهرة والزقازيق كنماذج عمل أصلية داخل المشروع لتوضيح كيفية هيكلة البيانات.
